# 银行柜面业务管理系统（Bank Counter Business Management System）

北京工业大学 软件工程课程设计 · 230710 班第 3 组（陈润田 / 陈镇岳 / 易裕杰，指导教师：付利华）

按《需求规格说明书》实现的银行柜面业务系统，覆盖储蓄、贷款、外汇、信用卡四大业务子系统与系统管理子系统，共 **5 类角色、10 个数据集合**；客户不直接登录，所有业务由柜面业务员/管理员代理办理。

## 技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 后端 | Python 3.11 + Flask 3 | 轻量、可读，一个业务子系统一个蓝图 |
| 数据库 | MongoDB（Atlas，PyMongo） | 资金类操作用多文档事务保证原子性 |
| 前端 | 原生 HTML/CSS/JS | 无需构建，声明式表单引擎（改需求只改一张声明表） |
| 外部行情 | Alpha Vantage（实时）+ open.er-api.com（兜底） | 外汇实时汇率，免费额度用尽回落当日参考价 |
| 部署 | Render + GitHub | 一键 Blueprint 部署，`gunicorn` 运行 |

## 功能一览

- **储蓄业务员（UC-101~108）**：开户注册（必填邮箱）、存款、取款、转账（本行/跨行）、账户明细查询、挂失/解挂/补卡、销户、客户信息更新
- **贷款业务员（UC-201~206）**：申请、审核审批（通过/拒绝/待补件）、放款、还款登记（含逾期罚息实时结算）、逾期管理与催收、查询统计
- **外汇业务员（UC-301/303/304/305/306）**：外汇子户开立、外汇买卖（显示人民币金额）、账户变更（冻结/解冻/注销）、余额历史查询、实时汇率查询（支持 9 种主流币种）
- **信用卡业务员（UC-401~406）**：申请、额度审批、账单生成、还款（全额/最低/部分）、预借现金、挂失/补卡/异常处理
- **系统管理员（UC-501~504）**：用户与权限管理、基础参数维护、日志审计、数据备份与恢复

四个公共用例（UC-INC-1~4：身份核验、账户校验、流水登记、审计日志）实现于 `common.py`，被各子系统复用。

## 设计亮点（答辩重点）

- **免输账号、凭身份办业务**：柜面办理业务只需填 **证件号 / 邮箱 / 手机号（任一）** 即可定位客户及其账户/卡/贷款/外汇子户并办理（`common.resolve_*`），账号/卡号仅在客户有多个时才需补充；本行转账收款方同样凭身份定位。
- **资金原子性**：所有资金操作在 `run_in_transaction` 事务内完成“校验—改写余额—写流水—写审计”，整体提交或整体回滚；Atlas 副本集原生支持事务，本地单机自动降级。
- **金额精度**：金额统一 `Decimal128`（DECIMAL(18,2) 语义），杜绝浮点误差；汇率 6 位、利率 4 位。
- **可追溯**：资金变动写 `business_transaction`，所有操作写 `audit_log`，历史数据不物理删除；账户余额与流水可对账（开户即补一条开户流水）。
- **安全**：密码加盐哈希；令牌含 `token_version`，改密/停用即令旧令牌全部失效（无状态吊销）；管理员不能停用/降权自己且保留末位管理员；参数维护白名单+非负校验。
- **备份恢复加固**：备份内嵌版本/记录数/MD5；恢复前校验版本+记录数+校验和，恢复后做逻辑外键完整性扫描，任一不过即回滚。
- **贷款罚息**：还款时按“剩余本金 × 日罚息率 × 逾期天数”实时结算，罚息优先冲抵、本息全清才结清。
- **外汇实时汇率**：单币种向 Alpha Vantage 实时拉取并按币种缓存 30 分钟；额度用尽/限流时回落 er-api 当日参考价。

## 本地运行

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt
copy .env.example .env            # 然后编辑 .env 填入 MONGODB_URI
python app.py                     # 访问 http://localhost:5000
```

## 部署到 Render

一键（推荐）：把仓库推到 GitHub → Render **New → Blueprint** 选中本仓库（读取 `render.yaml`）→ 填入 `MONGODB_URI` → 部署。
手动 Web Service：Start Command 用 `gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --timeout 120`；环境变量 `MONGODB_URI`（必填）、`DB_NAME=bank_counter`、`SECRET_KEY`。
> Atlas 需在 Network Access 放开 `0.0.0.0/0`（Render 出口 IP 不固定）。
